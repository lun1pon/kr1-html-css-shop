# Lunary Shop

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Lunary Shop — учебный многостраничный сайт интернет-магазина кроссовок в лунном стиле. Проект выполнен на HTML и CSS без фреймворков и без JavaScript.

## Структура проекта

- `index.html` — главная: hero, преимущества, популярные товары;
- `catalog.html` — каталог с карточками и блоком фильтров;
- `product.html` — карточка товара, таблица характеристик, модальное окно с размерной сеткой;
- `order.html` — форма заявки;
- `contacts.html` — контакты и частые вопросы;
- `css/style.css` — единый файл стилей;
- `images/` — SVG-иллюстрации и логотип;
- `.gitignore`, `README.md`.

## Используемые технологии

- HTML5 (семантическая разметка);
- CSS3: переменные, Flexbox, Grid, состояния `:hover` и `:focus-visible`, позиционирование, БЭМ;
- Git и GitHub Pages.
